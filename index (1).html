Which image format should I use?

  • JPG/JPEG: commonly used for photographs and smaller photo files; transparency is not supported.
  • PNG: useful for graphics, screenshots and images that need transparency; files can be larger.
  • WebP: a modern web image format that can provide good quality at smaller file sizes.
  • SVG: a vector format used for logos and illustrations. This tool can load SVGs for raster output, but it does not create editable vector SVGs.

Always keep a copy of your original file before editing. The best format and settings depend on where the image will be used.

How to Use Free Image Tools

Resize an image

  1. Open the Resize tab and choose an image.
  2. Enter the required width and height in pixels.
  3. Keep “Keep aspect ratio” selected to avoid stretching the image. If you change the width, the height adjusts automatically.
  4. Select Process image, review the output, and download it.

Crop an image

  1. Choose the Crop tab and upload your image.
  2. Enter Start X and Start Y to choose the top-left point of the crop area.
  3. Enter the crop width and height in pixels. Keep the rectangle within the original image dimensions.
  4. Process and download the cropped result.

Compress an image

  1. Choose Compress and upload your image.
  2. Move the quality slider lower for a smaller output file, or higher to preserve more detail.
  3. Process the image and compare the output file size with the original.
  4. Download the result if it meets your needs.

Convert an image

  1. Choose Convert and select an image.
  2. Choose JPG, PNG or WebP as the output format.
  3. Process the image, then download it. Choose PNG if you need transparent areas to remain transparent.

Helpful notes

  • Very large images may take longer or exceed your browser's available memory.
  • JPG does not preserve transparency; transparent areas may appear with a white background.
  • Animated GIFs are exported as a still image.
  • SVG files are rendered to pixels for output; this tool does not preserve vector editability.
  • Keep your original image until you have checked the downloaded file.
