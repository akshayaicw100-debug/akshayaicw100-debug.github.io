IMAGE REDUCER WEBSITE PACKAGE

Files included:
- index.html: home page and working image reducer
- assets/styles.css: responsive styling
- assets/app.js: browser-based image processing
- about.html, contact.html, privacy.html, terms.html: information and policy pages
- guides/how-to-compress-images.html and guides/jpg-png-webp.html: original guide drafts
- robots.txt and sitemap.xml

BEFORE PUBLISHING:
1. Replace REPLACE-WITH-YOUR-EMAIL@example.com in contact.html with a real email address you monitor.
2. Review the privacy policy and terms so they accurately describe your practices. The policy text is a starter template, not legal advice.
3. Check all pages, links and image processing on your own phone and computer.
4. If you add AdSense or analytics, update the privacy policy and consent setup to match the actual services.
5. Upload/extract these files into the ROOT of the GitHub Pages repository, preserving the assets/ and guides/ folders.
6. After deployment, open each page URL directly and confirm it loads (including nested guide pages).
7. Submit the sitemap in Google Search Console if you have verified the property.
8. Only request an AdSense review after reviewing Google's current policy details and making genuine improvements.

IMPORTANT:
This package improves site structure, usefulness, navigation and content. No code or template can guarantee AdSense approval. Review the guide text and add your own experience, real screenshots and tested examples before applying. The privacy and terms pages must match what the site actually does.
