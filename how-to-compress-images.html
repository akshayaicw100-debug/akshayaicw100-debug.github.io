PRACTICAL GUIDE

How to compress images without losing too much quality

A step-by-step approach to choosing the right dimensions, file format and quality setting for your image.

Guide • Beginner-friendly • Updated October 2026

1. Start with the purpose of the image

Before changing a file, decide where it will be used. A large photograph for a full-width page may need more pixels than a small thumbnail. A screenshot containing fine text needs careful inspection because compression artifacts can make text harder to read. If a form specifies a maximum file size or image dimension, use that requirement as your target.

2. Resize dimensions before chasing quality

Pixel dimensions affect how much image data must be stored. If an image is 4000 pixels wide but will only be shown at 800 pixels wide, a smaller version may be sufficient. Keep the original proportions when resizing to avoid stretching faces or objects. Do not enlarge a small image expecting it to gain real detail.

3. Pick a format that suits the image

JPEG is commonly used for photographs. PNG is useful for transparency, sharp edges and some graphics. WebP supports lossy and lossless compression and can be efficient for many web images. A conversion is not guaranteed to reduce file size, so compare the actual output.

See the companion guide JPG vs PNG vs WebP: choosing an image format for more detail.

4. Adjust quality gradually

For JPEG and WebP, quality settings trade some image fidelity for a smaller file. There is no single setting that works for every image. Begin with a moderate setting, preview the output at the size people will view it, and raise quality if you notice blockiness, blurry edges, banding or lost detail. PNG export generally does not use the same lossy quality control.

5. Compare the file size and preview

Record the original and output sizes. If the output is larger, try a different format or reduce dimensions where appropriate. A smaller file is only useful if the image remains fit for its purpose. Do not judge only from a tiny thumbnail; inspect details at a realistic display size.

6. Keep an original copy

Lossy compression can permanently discard detail. Keep the original file if you may need another export later. Avoid repeatedly opening and resaving the same lossy file; work from the original whenever possible.

Example workflow

  1. Choose a copy of the image, not your only original.
  2. Enter the maximum dimensions required by the destination.
  3. Export as JPEG or WebP for a photograph, or test PNG when transparency or crisp graphics matter.
  4. Preview the image and compare the output size with the original.
  5. Download only after checking that important details are still clear.
Practical tip: Do not claim a fixed percentage of savings for every image. The result depends on the image content, source format, dimensions, browser and export settings.
